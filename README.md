# KinoVSR

KinoVSR is an MLX-native video super-resolution and restoration toolkit for
Apple Silicon.

It grew out of the VSR harness and VideoToolbox/MLX restoration code that was
originally developed inside LTX-2-MLX. LTX-specific latent decoding remains an
adapter path; the core project is for video input, restoration, upscaling,
evaluation, and native macOS video I/O.
