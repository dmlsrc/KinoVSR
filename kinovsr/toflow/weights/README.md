# TOFlow Weights

TOFlow's released Torch7 `.t7` checkpoints are MIT-licensed with the upstream
project. The files in this directory are converted safetensors plus static graph
JSON files generated by
`python kinovsr/toflow/convert_t7_to_safetensors.py`; the runtime
never executes Lua/Torch code.

Bundled files:

| token | Torch7 source | use | sha256 |
| --- | --- | --- | --- |
| `denoise` | [`denoise.t7`](http://data.csail.mit.edu/tofu/models/denoise.t7) | seven-frame video denoise | `b53af3b138aa95161a9202d2f7cda07d95e0f9bd9d5278bc02e08087a276bda2` |
| `deblock` | [`deblock.t7`](http://data.csail.mit.edu/tofu/models/deblock.t7) | seven-frame video deblock | `8129ae76466987fa053ccd514c858b24f9232db85df273165589a1625921e445` |
| `sr` | [`sr.t7`](http://data.csail.mit.edu/tofu/models/sr.t7) | seven-frame 4x super-resolution residual over bicubic-upsampled input | `649cca805790142067f5b838dba30b6bdc5e17bc301b38613908f1983d3391e9` |
| `interp` | [`interp.t7`](http://data.csail.mit.edu/tofu/models/interp.t7) | two-frame interpolation helper | `18989ed88150c846d665abab51cc97e3bf25d2bd913298466587450479741520` |

Regenerate from a TOFlow reference checkout:

```bash
TOFLOW_REF=/path/to/toflow

python kinovsr/toflow/convert_t7_to_safetensors.py \
  "$TOFLOW_REF/models/denoise.t7" \
  -o kinovsr/toflow/weights/toflow_denoise.safetensors

python kinovsr/toflow/convert_t7_to_safetensors.py \
  "$TOFLOW_REF/models/deblock.t7" \
  -o kinovsr/toflow/weights/toflow_deblock.safetensors

python kinovsr/toflow/convert_t7_to_safetensors.py \
  "$TOFLOW_REF/models/sr.t7" \
  -o kinovsr/toflow/weights/toflow_sr.safetensors

python kinovsr/toflow/convert_t7_to_safetensors.py \
  "$TOFLOW_REF/models/interp.t7" \
  -o kinovsr/toflow/weights/toflow_interp.safetensors
```

Each conversion writes both `.safetensors` and a same-stem `.json` graph. Both
must be present for the corresponding runtime variant.
